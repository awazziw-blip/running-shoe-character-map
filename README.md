# Running Shoe Character Map — ASICS Pilot

Static mobile-first prototype for **Character Map / Match v1.1**.

## Core idea
Start from a shoe the reader already knows, then show only database-backed direct relations:
- Character profile across 7 axes
- Character Match %
- Directional Character Delta
- Direct Compare
- Change Direction filters

## Match v1.1 axes
Softness · Bounce · Stability · Guidance · Responsiveness · Agility · Comfort

**Not a quality score. Not a user-fit score.**

## Data
Prototype data lives in `data/asics.json`.
The Google Sheet remains the project source of truth; this JSON is a snapshot for the prototype.

## GitHub Pages
The site is static and can be served directly from the repository root on `main`.
